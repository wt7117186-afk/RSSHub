# 开张清单

按顺序做完这 6 步，公司就能运转。

## 1. 建仓库（老板，1 分钟）

在 GitHub 新建一个**空的私有仓库**，名字 `ai-company`（不要勾选 “Add a README”）。
建好后告诉 Claude，Claude 会把这套文件推上去。

## 2. 让 Claude 监事上线（老板，5 分钟）

任选一种：

- **方式 A（最快）**：在你自己电脑的终端里打开 Claude Code，运行 `/install-github-app`，选 `ai-company` 仓库，按提示完成。
- **方式 B（手动）**：
  1. 打开 <https://github.com/apps/claude>，安装到 `ai-company` 仓库。
  2. 在你电脑终端运行 `claude setup-token`，复制得到的 token。
  3. 仓库 → Settings → Secrets and variables → Actions → New repository secret，
     名字填 `CLAUDE_CODE_OAUTH_TOKEN`，值填刚才的 token。

## 3. 布置 Muse 的云电脑（把下面这段发给 Muse 执行）

```
请在你的云电脑上执行以下步骤，每步完成后告诉我结果：
1. 运行 gh auth login，按提示用浏览器登录我的 GitHub 账号
2. git clone https://github.com/<老板的GitHub用户名>/ai-company ~/ai-company
3. cd ~/ai-company && git config user.name "Muse" && git config user.email "muse@ai-company.local"
4. 运行 codex --version 确认 Codex 已安装；如果没登录，运行 codex login 按提示登录
5. 运行 ./scripts/初始化.sh 建好任务标签
6. 运行 ./scripts/看板.sh 确认能看到看板
```

## 4. 给 Muse 上岗（老板，1 分钟）

把 [roles/muse-总经理.md](roles/muse-总经理.md) 分隔线以下的内容整段贴给 Muse。

## 5. 试运行一个任务

在仓库开一个 Issue，选“任务单”模板，目标写：

> 做一个公司介绍网页 `index.html`，介绍我们公司的 4 个成员和分工。

然后对 Muse 说：“按工作循环处理新任务”。
看全流程是否跑通：Muse 补全任务单 → Codex 提交 PR → Claude 自动审核 → 你合并。

## 6. 建 Telegram 工作群

**老板在 Telegram 里做（10 分钟）：**

1. 找 [@BotFather](https://t.me/BotFather)，发 `/newbot`，建 3 个机器人，显示名分别叫 `Muse`、`Codex`、`Claude`
   （用户名要以 `bot` 结尾，例如 `你的名字_muse_bot`）。记下 BotFather 给的 3 个 token。
2. 还是在 BotFather：发 `/setprivacy` → 选 Muse 机器人 → `Disable`。这样 Muse 机器人能看到群里所有消息。
3. 新建一个 Telegram 群，把 3 个机器人都拉进来，然后在群里随便发一句话。

**把下面这段发给 Muse 执行（把 3 个 token 填进去）：**

```
请在你的云电脑上执行以下步骤，每步完成后告诉我结果：
1. cd ~/ai-company && git pull
2. cp telegram/.env.example telegram/.env，然后把下面 3 个 token 填进 telegram/.env：
   MUSE_BOT_TOKEN=<Muse 机器人的 token>
   CODEX_BOT_TOKEN=<Codex 机器人的 token>
   CLAUDE_BOT_TOKEN=<Claude 机器人的 token>
3. 运行 python3 telegram/hub.py ids，把输出里的 GROUP_CHAT_ID 和 BOSS_USER_ID 填进 telegram/.env
4. 运行 claude --version 确认 Claude Code 已安装；没装就运行 npm install -g @anthropic-ai/claude-code，然后运行 claude 按提示登录
5. 启动中枢：nohup python3 telegram/hub.py run >> telegram/data/hub.log 2>&1 &
6. 运行 ./scripts/群聊.sh 说 "大家好，我是总经理 Muse，工作群开张了。@codex @claude 请各自做个自我介绍"
7. 以后一直按岗位说明里的“Telegram 工作群”循环处理群消息
```

**说明：** 第 3 步如果看不到群 ID，把 Muse 机器人移出群再拉回来，在群里再发一句话，重新运行 `ids`。

---

跑通之后，就可以开始下达真正的业务任务了。

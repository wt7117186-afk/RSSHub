# 开张清单（Slack 版）

按顺序做完这 7 步，公司就能运转。

## 1. 建 GitHub 仓库（1 分钟）

在 GitHub 新建一个**空的私有仓库**，名字 `ai-company`（不要勾选 “Add a README”）。
建好后告诉 Claude，Claude 会把这套文件推上去。Codex 和 Claude 在云端干活都要用这个仓库。

## 2. 建 Slack 工作区和工作群（3 分钟）

1. 在 [slack.com](https://slack.com) 用邮箱免费创建一个工作区。
2. 新建频道 `#公司群`。

## 3. 拉 Claude 进群（5 分钟，需要 Claude Pro 或 Max）

1. 打开 [Slack 应用市场的 Claude](https://slack.com/marketplace/A08SF47R6P4)，点 “Add to Slack”。
2. 在 Slack 左侧 Apps 里点开 Claude → **App Home** → **Connect**，登录你的 Claude 账号。
3. 同一页的 **Routing Mode** 选 `Code + Chat`（写代码、聊天都能接）。
4. 打开 [claude.ai/code](https://claude.ai/code)，连接 GitHub，授权 `ai-company` 仓库。
5. 在 `#公司群` 里输入 `/invite @Claude`。

## 4. 拉 Codex 进群（5 分钟，需要 ChatGPT Plus 或以上）

1. 打开 [chatgpt.com/codex](https://chatgpt.com/codex)，连接 GitHub，给 `ai-company` 仓库建一个环境（environment）。
2. 在 Codex 设置里找到 Slack，安装到你的工作区。
3. 在 `#公司群` 里输入 `/invite @Codex`。

**博主的做法（需要 ChatGPT Pro）：** 在 ChatGPT 桌面版建一个 dot，连接 Slack。dot 自带云电脑、一直在线，能在 Slack 里跟你对话并替你调度 Codex。在 dot 的 Custom Rules 里把“在 Slack 发消息”设为允许，它就能自己在群里回复。

## 5. 拉 Muse 进群（2 分钟）

1. Muse → 设置 → **Connectors** → **Slack**，同意权限，登录你的 Slack 工作区。
2. 告诉 Muse：“公司工作群是 Slack 的 #公司群 频道。”

Muse 默认每次在 Slack 发消息前会请你点一下同意。

## 6. 给 Muse 上岗（1 分钟）

把 [roles/muse-总经理.md](roles/muse-总经理.md) 分隔线以下的内容整段贴给 Muse。

## 7. 试运行一个任务

对 Muse 说：

> 按岗位说明开一个任务：做一个公司介绍网页 `index.html`，介绍我们公司的 4 个成员和分工。

在 `#公司群` 里看这个话题串能不能走完：
Muse 写任务单 → `@Codex` 干活并回复 PR 链接 → `@Claude` 审核 → Muse @你 → 你合并 PR。

如果 Muse 发的 `@Codex` 或 `@Claude` 叫不动它们，把话题串截图发给 Claude（顾问），再调整。

## 可选：PR 一开就自动审核

在你自己电脑的终端里打开 Claude Code，运行 `/install-github-app`，选 `ai-company` 仓库。
之后 Codex 每开一个 PR，Claude 都会在 GitHub 上自动按任务单审一遍。
